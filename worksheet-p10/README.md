## Pertemuan 10 — JavaScript Asinkron
**Proyek:** Playlist Musik Favorit Saya
### Materi yang dipelajari
- Mengambil data JSON menggunakan `fetch()`.
- Memeriksa status respons dengan `respons.ok`.
- Menggunakan `async`, `await`, dan `try/catch`.
- Membaca respons menggunakan `respons.json()`.
- Memahami `JSON.parse()` dan `JSON.stringify()`.
- Memisahkan pengambilan data, alur aplikasi, dan tampilan halaman.
- Menangani keadaan memuat, berhasil, gagal, dan kosong.
