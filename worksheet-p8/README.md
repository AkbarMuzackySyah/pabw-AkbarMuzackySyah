## Ringkasan Fitur ES6+

| Fitur / Syntax | Peran dalam Kode |
|---|---|
| `const` & `let` | Deklarasi variabel konstan (`profil`) dan variabel fleksibel |
| Template Literals | Penggabungan string dinamis dengan sintaks `` `\${...}` `` |
| Spread Operator | Menyalin objek/array (`{ ...profil }`) tanpa mengganggu data asal |
| Array Methods | Pengolahan data menggunakan `map()`, `filter()`, dan `find()` |
| `console.table()` | Visualisasi data terstruktur di Console Browser |
