## Ringkasan Fitur DOM & Interaktivitas

| Fitur / Syntax | Peran dalam Kode |
|---|---|
| `querySelector` & `querySelectorAll` | Pemilihan elemen tunggal dan banyak elemen dari pohon DOM |
| `createElement` & `textContent` | Pembuatan elemen baru secara aman tanpa celah XSS |
| `addEventListener` & Event Delegation | Menangani interaksi klik filter secara terpusat di elemen induk |
| `event.preventDefault()` | Menghentikan pengiriman bawaan peramban agar halaman tidak dimuat ulang |
| `classList.toggle()` & Validasi | Pengelolaan status aktif tombol filter dan validasi formulir per kolom |
